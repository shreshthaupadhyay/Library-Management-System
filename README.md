Library Management System

A Java-based project developed to practise Core Java and Object-Oriented Programming (OOP) concepts.

Technologies Used

* Java
* Object-Oriented Programming (OOP)

Project Files

* Book.java — Represents book-related information.
* Library.java — Contains library management operations.
* Main.java — Entry point of the application.

Learning Objectives

* Practising Java programming
* Understanding classes and objects
* Organising a program into multiple Java files

Future Improvements

* Add book search functionality
* Implement book issue and return features
* Integrate a database for storing book records
